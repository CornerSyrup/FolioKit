# Agent-maintained templates

Users do not fill these files. The host copies and populates them as it interviews. Placeholder labels here are documentation aids, never valid production identities. Null values and empty arrays intentionally represent a workshop that has not started.

These are schema-valid draft records, not production-ready records. The production gate also needs resolved baseline dependencies, actual prompt/request files, actual files and hashes, tool evidence and visual review. The included framework validator does not certify a production release.
