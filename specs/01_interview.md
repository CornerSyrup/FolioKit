# Adaptive interview specification

The host is responsible for discovering inputs and writing records. Blank templates are internal aids, not forms the user must complete. Start useful work immediately using existing answers. Do not ask the user to restate information in this conversation.

| Discovery area | Ask only when needed | Record/result |
|---|---|---|
| Purpose | What will the kit support: drawing, modelling, reproduction, narrative, or another use? | Scope and acceptance priorities |
| Character and references | Existing character or new design? Which supplied sources govern which features? | Source register and authority map |
| Invariants | Which identity, shape, surface and costume details must remain consistent? | Versioned baseline |
| Variants | What can change, and which variant is being produced now? | Variant rules and dependencies |
| Poses and viewpoints | Which exact poses matter? Which are emotional concepts? What coverage is needed? | Panel inventory with evidence |
| Rendering | What style, lighting and background make references useful? | Generation profiles |
| Operation | Any budget, batch or time constraints? | Round policy; quality remains unchanged |
| Delivery | Atlas PNG + PDF and HTML are standard; what presentation or device needs affect layout? | Delivery profile |

Ask normally 1–3 related questions per turn. Use plain language, understandable alternatives and room for free text. Explain why a missing identity-critical detail matters. Ask user preferences rather than pretending the user knows tool metadata. The agent investigates tool capability itself.

Each answer becomes a decision with ID, timestamp, user wording or evidence, interpreted requirement, scope, status and affected dependencies. A decision can supersede another; preserve the history. Proposed defaults remain explicitly proposed until settled by an explicit answer or a clearly authorised routine choice.

Do not ask for blanket approval at every stage. Clarification is needed for unresolved consequential choices; proceed independently on reversible tasks. Do not generate dependent production panels while their baseline is unknown. You may still organise sources, prepare plans and draft interview questions.

If user says “use your judgement”, record the delegated scope and choose within it. Do not interpret this as evidence for an inaccessible source. If user pauses or a tool is unavailable, produce a resume note rather than pretending work finished.
