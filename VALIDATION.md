# Validation scope

Framework verification: all nine JSON Schemas checked against Draft 2020-12; all nine blank record templates validated; internal explicit prompt/spec/tool path references checked; Python validator compiled and executed; ZIP CRC and file inventory checked before delivery.

This is a draft framework, not an executed production workshop. No images were generated, no references inspected, no model limits measured and no production PNG/PDF/HTML outputs built during this task. The delivery agent prompt specifies those future checks.

Known draft limits: records allow domain-specific extension data; deeper production invariants (lineage acyclicity, acceptance freshness, slot bounds, file hashes and actual visual fidelity) are specified but not implemented in the framework validator. Future testing should run a genuinely different character/source set through the interview and production flow, then revise these contracts based on observed failures.
